# Первичный аудит безопасности

**Статус:** частично завершён 9 октября 2026 года. Анализ основан на текущем исходном коде и конфигурации; production-среда не предоставлена и не проверялась.

## Подтверждённые результаты

### SEC-001 — внешний доступ к runtime-метрикам

- **Приоритет:** P2.
- **Компонент:** nginx / наблюдаемость.
- **Доказательство:** backend публикует `/metrics` в `backend/src/main.ts`; общий nginx location `/api/` проксировал этот путь наружу в `nginx/proctolearn.conf`.
- **Последствие:** удалённый пользователь мог получить технические сведения о процессе и нагрузке, полезные для разведки.
- **Исправление:** добавлен точный location `/api/metrics`, возвращающий `404` до общего proxy location. Prometheus продолжает обращаться к `api:4000/metrics` по приватной application network согласно `monitoring-project/prometheus/prometheus.yml`.
- **Статус:** исправлено в конфигурации; production nginx не проверен, поскольку доступ к нему не предоставлен.

## Проверенные границы

- JWT strategy повторно читает роль и `tokenVersion` из базы.
- Для изменяющих HTTP-запросов CSRF guard требует разрешённый Origin и HMAC header.
- Сессионные cookies имеют подходящие флаги HttpOnly и secure-политику для production.
- Загрузка evidence проверяет владельца попытки перед сохранением chunk, а просмотр использует проверку назначения проктора и короткоживущие signed URL.
- Отслеживаемых реальных `.env`, private key или токенов в Git не найдено. Значения demo/test не считаются доказательством отсутствия скомпрометированных ранее внешних ключей.
