# Контролируемый пилот ProctoLearn

Владелец: Arsen. Дата проверки документа: 10.10.2026. Это ограниченный учебный пилот по расписанию, не круглосуточный production. AI выключен: прежняя проверка казахского локального помощника не достигла принятого порога. Демо остаётся отдельным профилем.

## Состояние доступа

Публичный адрес нового пилота **не назначен и не проверен**: клиент и аккаунт ngrok пока не настроены. Не приглашайте участников по старому временному адресу проверки QR: тот шлюз открывает только проверку двух вымышленных сертификатов.

Локальные адреса после успешного `start`: приложение через ограниченный шлюз `http://127.0.0.1:3200`; кабинет владельца `http://127.0.0.1:3200/dashboard/admin/pilot`. Эти адреса работают на ноутбуке; на телефоне localhost означает сам телефон. Кабинеты сотрудников доступны через локальный HTTP режим шлюза; через публичный HTTPS режим закрыты. Для редакторской работы остановите объявленную сессию и запустите локальный режим либо используйте авторизованный локальный importer. Тесты мобильного viewport не заменяют проверку физического телефона.

## Единственный профиль и команды

Из корня репозитория, PowerShell7, Node24.15+ и существующий PostgreSQL18/SeaweedFS launcher. DPAPI author backup проверен на PowerShell7.6.5/.NET; Windows PowerShell5.1 его современные cryptography API не поддерживает:

```powershell
node scripts/pilot-profile.cjs prepare
node scripts/pilot-profile.cjs validate-update
node scripts/pilot-profile.cjs promote
node scripts/pilot-profile.cjs start
```

`start` держит процессы в текущем терминале. Отдельный терминал:

```powershell
node scripts/pilot-profile.cjs status
node scripts/pilot-profile.cjs stop
node scripts/pilot-profile.cjs backup before-update
node scripts/pilot-profile.cjs restore-check before-update
```

Используются только `.local/pilot`, собственные БД `proctolearn_pilot`, bucket `proctolearn-pilot`, PostgreSQL5434, S39100, Next3100, API4100, proxy3200. Все сервисы слушают loopback; наружу разрешается только HTTPS маршрут к proxy. Маркер владельца защищает от принятия неизвестного каталога. Нет reset на сайте или в этой последовательности.

Учётная запись владельца и случайный пароль находятся в `.local/pilot/PILOT_ACCESS.txt`; не переносите файл, снимки кабинета с реальными именами и `.env.local` в Git/чат. Этот профиль не меняет пароли демо. Перезапуск не создаёт новых участников и не обнуляет их работу.

## Бесплатный HTTPS через ngrok

Нужны согласие владельца на официальный локальный клиент, вход в собственный [dashboard ngrok](https://dashboard.ngrok.com/) и назначенный аккаунту development hostname. Токен вводится через интерфейс провайдера/его локальную настройку; никогда не отправляется в чат. Покупка домена не требуется. Домен — имя, tunnel — маршрут к работающему ноутбуку; база, файлы и локальная модель не переезжают в облако.

`prepare` создаёт приватную `.local/pilot/ngrok-traffic-policy.yml`. Политика сначала удаляет присланные посетителем заголовки доверия, затем выставляет секрет шлюза и IP из `conn.client_ip`. Внешний режим шлюза требует оба значения. Не заменяйте эту схему доверием к произвольному `X-Forwarded-For`. Инспекция HTTP выключается, чтобы провайдерская локальная панель не сохраняла пароли/приглашения/ответы.

После подключения аккаунта оператор подставляет **фактическое назначенное имя** в локальную конфигурацию origin и команду:

```powershell
ngrok http http://127.0.0.1:3200 --url https://<назначенное-аккаунту-имя> --traffic-policy-file .local/pilot/ngrok-traffic-policy.yml --inspect=false
```

Это инструкция, а не уже выполненный запуск. Перед запуском профиля задать `$env:PILOT_PUBLIC_APP_URL='https://<назначенное-аккаунту-имя>'` в его терминале; launcher передаст этот origin в FRONTEND_URL и CERTIFICATE_PUBLIC_ORIGIN. Перед участниками обязательно проверить фактические entitlement/расход в dashboard, CLI policy, TLS cookies/CSRF, двух клиентов с разными IP, поддельные forwarding headers, WebSocket, загрузки и отсутствие запросов телефона к приватным адресам. Совместимость политики с установленной версией клиента пока не подтверждена.

По официальным страницам на10.10.2026: Free —1GB исходящего трафика/месяц,20000HTTP requests/месяц,5000TCPconnections/месяц,10000logevents/месяц;4000HTTPrequests/min,100TCPconnections/min;3onlineendpoints/agents,1accountmember,1assigneddevelopmentdomain,5TrafficPolicyrules/policy. Один участник аккаунта провайдера не означает одного посетителя сайта. Traffic Policy расходует учитываемые провайдером единицы; остатки/кредит конкретного аккаунта неизвестны. Нельзя обещать нулевой расход или неограниченных студентов без dashboard.

Источники: [Free limits](https://ngrok.com/docs/pricing-limits/free-plan-limits), [учёт тарифов](https://ngrok.com/docs/pricing-limits), [домены](https://ngrok.com/docs/gateway/domains), [add headers](https://ngrok.com/docs/gateway/traffic-policy/actions/add-headers), [remove headers](https://ngrok.com/docs/gateway/traffic-policy/actions/remove-headers), [CLI](https://ngrok.com/docs/gateway/agent/cli). Для HTML Free показывает предупреждение до загрузки страницы. Кнопка Visit подавляет его cookie на7дней; JavaScript приложения не может убрать первый экран. Оператор проверяет обычное открытие с телефона через предупреждение.

Cloudflare [Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/) — только временный preview/QR, со сменой имени и ограничениями разработки. Он не подменяет принятый стабильный origin и не является постоянным адресом сертификатов. Даже development hostname ngrok зависит от жизненного цикла аккаунта: позже нужен согласованный постоянный адрес и миграция QR-ссылок.

## Приглашения, места и доступ

Начальная группа —10 взрослых добровольцев, приглашённых владельцем. Это число участников, не измеренная мощность видеоэкзаменов. Настройки проверяются сервером: `PILOT_MODE=true`, `PILOT_MAX_PARTICIPANTS=10`, `PILOT_DEFAULT_COURSE_SEATS=10`, `PILOT_PUBLIC_SIGNUP=false`; открытая регистрация в этом режиме отклоняется.

В локальном кабинете владельца: создать приглашение на конкретный email, однократно скопировать токен и передать лично через согласованный канал. По умолчанию оно действует24часа, может быть отозвано и погашается один раз. Сервер хранит digest, назначает STUDENT и создаёт индивидуальную учётную запись. Внешняя почта не настроена; mail catcher не является доставкой студенту. Публичное восстановление пароля закрыто, интерфейс направляет к администратору. Не раздавайте общий пароль.

Лимит группы учитывает всех принятых участников, включая SUSPENDED, и неистёкшие неотозванные приглашения. Приостановка не освобождает место жизненного состава группы. Лимит курса отдельно учитывает ACTIVE enrollments. Повторная запись идемпотентна; гонка за последним местом проходит сериализуемую транзакцию. Withdrawal сохраняет оценки, ответы, прогресс и сертификаты; активный неистёкший экзамен препятствует освобождению места. Администратор может приостановить/возобновить доступ, посмотреть разрешённый прогресс и снять запись с курса. Приглашение не означает прохождение или выдачу сертификата.

До первой загрузки персональных данных/записей нужны согласование владельца, информированное добровольное участие, раскрытие записи и применимые разрешения учреждения. Галочка не доказывает юридическое соответствие. Не используйте реальные данные в тестах, Git, AI prompts и публичных снимках.

## Обновление и восстановление

1. Проверить отсутствие активного экзамена, объявить обслуживание, остановить пилот.
2. Сделать свежий backup после последней остановленной сессии и `restore-check`. Историческая копия до последующего запуска не разрешает promotion.
3. Выполнить актуальные локальные тесты и `validate-update`. Это отдельная production сборка, не `next dev`; исходные правки/пуш сами не обновляют сайт.
4. Предпросмотр владельцем до приглашения участников или в обслуживании; явный `promote` только при остановленном профиле. Сохранён предыдущий артефакт; версия показывается владельцу.
5. Запустить принятый артефакт, проверить свой origin, вход/прогресс/QR, затем открыть объявленную сессию. Не смешивать старый HTML с новыми assets.

`restore-check` создаёт отдельную случайно именованную БД/bucket, сверяет их с копией и сохраняет точные имена в приватном `.local/pilot/restore-<suffix>.json`. Копии содержат те же персональные данные, остаются loopback и требуют операторского учёта срока хранения. Не удаляйте их по маске: сначала проверьте конкретное имя/маркер и отсутствие использования, затем отдельно согласуйте очистку. Нет обещания мгновенного отката через несовместимую схему. Recovery означает старый артефакт с отдельной восстановленной парой данных/файлов.

## Учебные черновики и проверка владельцем

```powershell
node scripts/curriculum-validate.cjs
node scripts/curriculum-import.cjs --profile=pilot
node scripts/curriculum-import.cjs --profile=pilot C01 --apply
./scripts/pilot-author-backup.ps1 -Operation backup
```

Импорт по умолчанию dry-run. `--apply` использует авторизованного локального владельца и только точный pilot profile. Создаёт DRAFT атомарно, хранит authoring ID/hash/map, безопасно повторяется и останавливается при правках учителя. Не переписывает опубликованное, не обнуляет прогресс и не публикует автоматически. После major change требуется новая редакция курса; параллельной draft/live версии платформа не обещает.

Секретные банки/решения и import-map лежат в `.local/pilot-author`, вне публичного Git. Зашифрованная DPAPI копия сохраняется вне репозитория в `ProctoLearn-private-backups` пользовательской папки Документы. Скрипт расшифровывает в памяти и сверяет каждый файл. Для утраты машины нужны отдельно защищённая off-device копия и Windows account keys; ignored-файл сам по себе не backup.

Владелец/преподаватель открывает каждый DRAFT в существующем редакторе, читает объяснения, выполняет примеры/практику, проверяет однозначность вопросов и соответствие целям, источники/лицензии, клавиатуру и узкую ширину. Предложенные75% и длительность экзамена требуют действительного решения, не являются правилом учреждения. Проекты SELF_ASSESSED, без вымышленной проверки преподавателем. До реального approval статус HUMAN_REVIEW_PENDING; согласие с количеством не разрешает публикацию невиданных уроков.
