# ProctoLearn — Hybrid Premium UI/UX

Дата: 9 октября 2026. Ветка: `feat/hybrid-premium-redesign`.
Исходная точка: `de54c6577350dc4ca0a580498151394d4868ae73` из `audit/diploma-release-20261009`.

## Исходное состояние

Публичная часть и рабочие страницы использовали одинаковые светлые шаблоны, разрозненные отступы и преимущественно синие акценты. Верхнее меню плохо масштабировалось с количеством ролевых ссылок. Авторизация не имела общей композиции; у регистрации отсутствовала часть связей label/input. Внутренний каталог загружал декоративные изображения с внешнего сервиса. Некоторые второстепенные подписи имели слабый контраст. Переиспользуемые компоненты существовали, но не задавали единого визуального языка.

Существующие GooeyNav, LiquidEther, MagicBento и GSAP просмотрены. Для новой главной выбран спокойный SVG/CSS интерфейс и отдельная лёгкая геометрическая сцена Three.js. Старые компоненты и зависимости не удалены в рамках этой задачи.

## Что изменено

- Главная: тёмная тема, стеклянная навигация, адаптивное меню, крупная типографика, интерактивный геометрический hero, SVG-категории технологий, асимметричная сетка возможностей, реальный каталог с фильтром/повтором загрузки, этапы обучения, CTA и footer.
- `/courses`, `/courses/[id]`: тёмное оформление, детерминированные обложки, счётчик/фильтры/пагинация, программа курса, breadcrumbs и существующий переход регистрации.
- Все четыре auth-страницы: общий split-screen, мобильная форма, autofill, видимость пароля, доступные подписи и ошибки. Политика пароля и обработчики авторизации сохранены.
- Dashboard: светлый sidebar/topbar, ролевые ссылки, мобильный native dialog, фокус и Escape, уведомления и профиль. Существующее исключение shell для экзамена сохранено.
- Student: приветствие, реальные показатели, курсы, прогресс, обучение, результаты и сертификаты.
- Teacher: списки курсов, создание/редактирование, обучение и формы используют общий набор поверхностей и отступов; все действия сохранены.
- Proctor: попытки, статусы, Trust Score и доказательства оформлены как рабочая область без декоративного движения.
- Admin: сводка, таблицы, пользователи/курсы/online/audit, адаптивная прокрутка; диалоги выдачи доступа и временного пароля получили native modal semantics.
- Exam: CSS module, читаемые ответы, видимый таймер, текстовый прогресс и native progress, согласованный DOM/визуальный порядок. Анимации внутри экзамена отключены.
- Сертификаты и публичная проверка: аккуратные карточки, QR/PDF и реальные состояния API; оформление не меняет правила выдачи/проверки.

Часть внутренних страниц получает оформление через общий `dashboard.css`; это не отдельная новая реализация бизнес-сценария на каждой странице.

Inter остаётся локальным: файл `InterVariable.woff2` проверен через cmap; все `ӘәҒғҚқҢңӨөҰұҮүҺһІі` присутствуют. Лицензия сохранена. Заголовки используют responsive scale и перенос длинных слов.

Переиспользуемые элементы:

- `PremiumAuthFrame`: единая композиция авторизации.
- `PremiumPublicFrame`, `CourseCoverArt`, `PublicLoadingCards`: публичные страницы.
- `PremiumSections`: категории, возможности, процесс и CTA.
- `WorkspaceDialog`: modal semantics, блокировка прокрутки, Escape и восстановление фокуса.
- `LoadFailure`: общее отображение отказа с повтором.

## 3D и движение

`PremiumHeroScene` лениво подключает `KnowledgeScene` только на десктопе, в видимой области, при видимой вкладке и разрешённом движении. Сцена содержит прозрачный куб, внутренний многогранник и орбиту. DPR ограничен 1,5; кадры запрашиваются только при изменении размера/указателя и пока объект плавно принимает положение. Постоянного idle render loop нет.

При размонтировании освобождаются геометрии, материалы, renderer, RAF, observers и listeners. При недоступном WebGL используется CSS-объект. Проверено реальное событие потери/восстановления контекста через `WEBGL_lose_context`. На мобильном и при reduced motion WebGL chunks не загружаются. Canvas декоративный и находится вне кликабельных элементов.

Hover ограничен коротким изменением цвета/границы/положения карточки. Глобальный reduced-motion отключает движение. Экзамен использует дополнительное локальное отключение анимаций.

## Проверки интерфейса и доступности

- Новый `frontend/e2e/premium-ui.cjs`: 6 публичных страниц × 10 ширин (320, 360, 375, 390, 430, 768, 1024, 1280, 1440, 1920), без горизонтального overflow; axe WCAG A/AA и 2.2 AA tags — без найденных нарушений. Проверены фильтр, пустой результат, 503/повтор, Escape и возврат фокуса.
- Дополнительные UI fixtures: 4 роли × 4 ширины, без overflow, runtime errors и найденных axe-нарушений; native drawer и admin dialog проходят focus/Escape.
- Детали курса, валидная проверка сертификата и форма reset с токеном: 12 комбинаций viewport/axe без найденных нарушений.
- Изолированная проверка WebGL: desktop default, mobile default, desktop reduced motion, недоступный контекст и context restore.

Fixtures используются только в тестах. Скриншоты с тестовыми курсами/пользователями обозначены в артефактах и не являются результатами реального API. Автоматическая axe-проверка не подтверждает полное соответствие WCAG: ручная проверка экранным диктором, Safari/Firefox и физической камерой остаётся отдельной задачей.

Независимое ревью выявило и помогло исправить восстановление RAF после context loss, неверный формат ответа каталога в новом тесте, контраст hover CTA и порядок фокуса в экзамене. Live E2E дополнительно выявил контраст Trust Score; он исправлен. Селекторы старого E2E обновлены для новых заголовков и dialog меню; проверки поведения не удалялись.

## Производительность

Методика: локальный Chrome, production webpack builds исходного commit и новой версии, 5 свежих браузерных контекстов на профиль, одинаковый пустой API fixture, без сетевого/CPU throttling, fonts.ready и 3 секунды наблюдения. CLS — максимальное session window (gap 1 s/cap 5 s). Это лабораторные данные, не полевые Core Web Vitals.

| Медиана | Mobile до → после | Desktop до → после |
|---|---:|---:|
| LCP | 364 → 208 мс | 444 → 224 мс |
| CLS | 0,007855 → 0,000064 | 0,001077 → 0,000025 |
| JS decoded | 594 871 → 582 543 Б | 594 871 → 1 145 193 Б |
| JS transferred | 188 022 → 181 314 Б | 188 022 → 327 921 Б |

Desktop получает дополнительные отложенные Three.js chunks; mobile их не получает. Максимальные LCP в выборках достигали 1212 мс до и 1240 мс после, поэтому небольшие различия медиан не следует считать гарантией ускорения. INP не измерен. Целевые LCP/CLS/INP в условиях реальных пользователей не подтверждены.
