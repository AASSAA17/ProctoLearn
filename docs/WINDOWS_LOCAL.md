# Локальный запуск на Windows

Команды выполняются из папки репозитория, например `C:\Users\Arsen\ProctoLearn`. Перед запуском обновите её: `git pull --ff-only`.

## Через Docker Desktop

Установите Node.js 24 LTS (24.15+) и Docker Desktop. Запустите Docker Desktop и дождитесь `Engine running`, затем в PowerShell:

```powershell
cd C:\Users\Arsen\ProctoLearn
.\start-local.cmd --demo-minimal
```

Сайт: http://localhost:3000. API readiness: http://localhost:4000/ready. Первый запуск собирает образы и применяет миграции. `--demo-minimal` создаёт четыре учебные роли, один курс, урок и экзамен. `--demo` добавляет большой набор курсов с черновыми материалами; без обоих флагов база остаётся пустой. Пароли генерируются индивидуально и сохраняются только в `.local\DEMO_ACCESS.txt`. После самостоятельной смены пароля эта памятка не обновляется. Повторный seed не удаляет существующие курсы и не заменяет пользовательские данные.

Остановка без удаления данных:

```powershell
docker compose --project-name proctolearn-local --env-file .env.local -f docker-compose.local.yml down
```

Не добавляйте `-v`: этот флаг удаляет volumes.

## Без Docker

Если Docker Desktop недоступен, нужны Node.js 24 LTS (24.15+), PostgreSQL 16 или новее и штатный Windows `tar.exe`. Установленная служба PostgreSQL не используется: создаётся отдельный кластер в `.local\postgres`, доступный только на `127.0.0.1:5433`.

```powershell
.\start-local.cmd --native --demo-minimal
```

Скрипт скачивает зафиксированные npm и SeaweedFS из официальных источников, проверяет их контрольные суммы, устанавливает зависимости, собирает приложение, применяет миграции и запускает сервисы. Вспомогательные процессы скрыты; окно PowerShell остаётся открытым. `Ctrl+C` останавливает созданные им сервисы. Не закрывайте окно принудительно. Журналы находятся в `.local\logs` и могут содержать приватные технические данные.

Если Node отсутствует в PATH, CMD-обёртка также проверяет уже установленный локальный runtime Codex. На другом компьютере достаточно обычной установки Node.js. Для выбора PostgreSQL установите `$env:POSTGRES_BIN = 'C:\Program Files\PostgreSQL\18\bin'`. Скрипт сверяет major с локальным кластером и не обновляет его автоматически.

После успешной сборки можно использовать `--skip-build`, пока код и lock-файлы не менялись. После `git pull` снова запускайте без этого флага. Также доступна PowerShell-обёртка `scripts/start-local.ps1` с параметрами `-Native`, `-DemoMinimal`, `-Demo`, `-SkipBuild`, `-PrepareOnly`, если политика PowerShell разрешает скрипты. CMD-обёртка и прямой `node scripts/local-launch.cjs` не меняют эту политику.

## Сохранность существующего проекта

- Старый `.env`, отчёты и прежние volumes `proctolearn` не изменяются. Новый файл `.env.local` содержит отдельные случайные ключи. Повторный запуск не заменяет существующие ключи.
- Docker использует проект `proctolearn-local`; native хранит файлы только в `.local`. Это два независимых набора данных. Не переключайтесь между ними, ожидая одинаковую базу.
- Старые записи MinIO нельзя открыть, просто подключив его каталог к SeaweedFS. Перенос выполняется через S3 API с проверкой объектов и согласованной базой; прежнее хранилище сохраняется до проверки переноса.
- Если порт занят, скрипт останавливается. Он не завершает посторонние процессы и не удаляет данные.
- `.env.local` и `.local` исключены из Git. `--prepare-only` только создаёт/проверяет конфигурацию, не запускает сервисы.

Это локальное окружение с HTTP и cookies development. Для публичного сервера нужны HTTPS, same-site домены frontend/API, SMTP и отдельные настройки хранения. См. [сессии](AUTH_SESSIONS.md) и [записи](RECORDINGS_AND_APPEALS.md).

Бесплатный домен пока не нужен для `localhost`. Привязка будущего домена не состоит из замены одной ссылки: нужны сервер или хостинг с постоянным PostgreSQL/S3, DNS, HTTPS для сайта/API/загрузок, новые приватные ключи и проверка камерных разрешений в браузере. Не размещайте demo-пароли и локальную БД в публичной среде. Порядок проверки: [RELEASE_RUNBOOK.md](RELEASE_RUNBOOK.md); задачи по интерфейсу и минимальному выпуску: [MVP_LOCAL_AND_FRONTEND_PLAN.md](MVP_LOCAL_AND_FRONTEND_PLAN.md).
