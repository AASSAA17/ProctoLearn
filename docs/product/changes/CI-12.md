Обычная Docker-сборка находит исходные assets, поэтому её CI не воспроизводил отдельный pilot layout.

- Проверки: новая проверка копирования шрифтов и лицензии, отсутствующего/пустого файла — PASS. Первый совместный запуск proxy-тестов заблокирован работающим API на 4100 (EADDRINUSE), после штатной остановки 17/17 profile/proxy PASS. `git diff --check` PASS.
