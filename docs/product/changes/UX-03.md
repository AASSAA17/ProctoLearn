## Проверенный исходный контракт

- Формативные шаги `TASK` отправляют ответ в `POST /steps/:id/submit` и получают только `isCorrect` и `score` для ученика. Backend намеренно возвращает `explanation: null` и `correctAnswer: null`.
- Закрытые ответы итогового экзамена и преподавательские ключи в учебный компонент не передаются. UI не должен выводить или вычислять их.
- Шаги `TEXT` и `VIDEO` сохраняются через `POST /steps/:id/complete`. После этого UI сверяет `GET /submissions/lesson/:lessonId/progress`; завершение урока отправляется только после серверного подтверждения всех обязательных шагов.
- После правильного `TASK` текущий UI уже вызывает сохранение прогресса автоматически, но затем повторно показывает действие «Прогресті сақтау». Это создаёт повторный запрос завершения урока и вводит ученика в заблуждение.
- Любой `videoUrl` сейчас открывается в `iframe`, а HTML разрешает iframe без отдельной проверки origin. Требуется разделить прямое медиа и ограниченные embed-источники, сохранив очистку HTML.
- Выбранный шаг хранится только в React state. При переходе по боковой навигации URL не обновляется, поэтому refresh/back не сохраняют текущую точку обучения.

## Границы педагогической обратной связи

- **Формативная практика:** показывает факт правильного/неправильного ответа, безопасную подсказку перечитать материал и возможность повторить. Разрешённая backend-подсказка может отображаться только если она явно пришла в ученическом ответе.
- **Итоговый экзамен:** остаётся в отдельном экзаменационном потоке; этот компонент не показывает ответы или объяснения экзамена.
- **Материалы преподавателя:** ключи и приватные объяснения не выводятся в learner UI и не используются для локальной проверки.
