## Ограничения

- API записей на курс возвращает агрегированный прогресс и не возвращает идентификатор последней открытой страницы. Поэтому действие продолжения ведёт на точную страницу курса, где уже выбирается следующий незавершённый доступный урок.
- Ответы текущих API не дают безопасно отличить незавершённую загрузку записи экзамена от других причин ожидания проверки. Такой статус не будет выдуман в интерфейсе.
- Текущий `/attempts/my` не возвращает состояние загрузки записей камеры/экрана. Кабинет честно показывает доступное состояние проверки и не заявляет, что загрузка доказательств завершена или не завершена.
- Для компактности главная страница показывает не более трёх последних курсов в блоках продолжения и пути к сертификату; полный список остаётся на страницах курсов, результатов и сертификатов.
