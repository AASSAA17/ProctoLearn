# Существующая Hybrid Premium система

Публичные страницы: тёмные #080b14/#101525, violet/cyan акценты. Рабочие кабинеты: светлые #f6f7fb/white, тёмный текст, violet primary. Источник токенов — frontend/src/app/globals.css и dashboard.css; используем существующие ui.tsx/PremiumAuthFrame/PremiumPublicFrame.

Локальный Inter с казахской кириллицей. Отступы кратны существующим 4/8px шкалам, radius 10/14/20/24px, состояния focus-visible/error/disabled различимы без одного цвета. Главная кнопка одна на смысловой блок; опасное действие требует понятного последствия и отмены. Никаких придуманных рейтингов и статистики.

Семантические label/input, связанные ошибки, aria-live для результата, модальные native dialog с Escape/возвратом фокуса. Кнопки основных действий минимум 44px, перенос длинных слов, горизонтальная прокрутка кода/таблицы в собственном контейнере. Ошибка загрузки отличается от реального нуля и пустого результата.

3D только как декоративное дополнение главной: lazy import, reduced-motion, статичная замена, остановка вне viewport/скрытого документа, освобождение GPU. В экзаменах и evidence review 3D отсутствует. Текст и навигация доступны без WebGL.

Термины интерфейса: курс, сабақ, тапсырма, емтихан, сертификат, шақыру; нормальные пользовательские сообщения на казахском. Технические identifiers/code сохраняются. Полный исторический дизайн: [HYBRID_PREMIUM_REDESIGN](../HYBRID_PREMIUM_REDESIGN.md).
