# ProctoLearn: продукт и реальные ограничения

Обновление: 20.10.2026. Четыре роли: STUDENT учится; TEACHER управляет своими курсами; PROCTOR проверяет назначенные сессии; ADMIN управляет платформой. Backend определяет доступ, оценивание и выдачу сертификатов.

Путь: каталог → регистрация → запись → материалы и задания → допуск к экзамену → экзамен и запись → проверка → сертификат → QR-проверка/отзыв. Завершение урока не означает сдачу экзамена; балл не означает одобрение проктора.

## Действующий режим

По отдельному решению владельца 19.10 регистрация открыта (`PILOT_MODE=false`), C01–C15 опубликованы как предварительные материалы. Проверка преподавателем остаётся PENDING. Закрытый пилот с приглашениями поддерживается отдельно при `PILOT_MODE=true`; изменения UX не должны сами переключать режим. Перед регистрацией интерфейс должен получать актуальную политику сервера, а не угадывать её по адресу сайта.

Данные сохраняются в отдельном `.local/pilot`; demo/test — другие профили. Приватные ключи ответов, записи и пароли не входят в Git. Доступ к черновикам и preview — только владелец курса/ADMIN. Preview не создаёт академические записи.

## Ограничения

Нет общего запуска пользовательского кода, ручного essay grading, параллельных live/draft редакций, подтверждённого 24/7 хостинга, подтверждённой доступности с физического телефона или пройденного Kazakh local AI gate. Ollama необязателен и выключен. Внешняя почта и постоянный HTTPS адрес не настроены. Предварительные курсы не являются академически утверждёнными.
