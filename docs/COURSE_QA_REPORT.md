## Примеры и доказательства

Проверка структуры выполнена для всего пакета. Проверки примеров и оценивания ведутся отдельно: фактические результаты записываются в ignored evidence-файлы `.local/pilot-author/`; актуальную сводку запуска приводит основной `TEST_RESULTS.md`. Не следует считать все 150 примеров исполняемыми программами: среди них есть HTML/CSS/JSX-фрагменты, протоколы review, модели политики и операторские сценарии. Для таких примеров нужны подходящий fixture либо проверка человеком.

Подтверждённые на момент составления этого отчёта проверки: C01 — 11 примеров Chrome, последний урок содержит протокол; C02 — 9 примеров Python 3.12.14; C03 — 9 примеров на отдельном PostgreSQL fixture; C04 — 12 примеров Chrome/локальный HTTP; C05 — 8 упражнений Git на новых локальных репозиториях, включая bare remote, без публикации в чужой аккаунт; C06 — 9 упражнений Bash в Git for Windows. Последнее не доказывает native Linux permissions. Эти результаты получены основной задачей и доступны в её реальных evidence-файлах; они не были придуманы автором контента.

Дополнительно фактически выполнены C07: 11 React-примеров в Chrome; C08: 9 strict TypeScript/runtime-проверок и 2 отрицательных type-fixture; C10 L01–09: 9 проверок реального loopback HTTP с Express 5.2.1; C13 L04–07: 4 проверки Node/HTTP; C14 L01–08: 8 Python-примеров; C15 L01, L02, L04–07: 6 примеров pandas 3.0.1/matplotlib 3.11.2, включая созданный PNG графика. C01 L03 проверяет реальные значения относительных href, но переход между физическими файлами не заявлен.

Итого **105 уроков имеют выполненную техническую проверку примера**, включая **9 проверок shell-семантики в Git for Windows**, которые не являются native Linux evidence. **45 примеров остаются протоколами/дизайн-упражнениями для человека либо ожидают отдельной среды.** Статусы и scope указаны поурочно в манифесте; полные evidence остаются приватными. G4 не объявлен полностью пройденным: Docker и native Linux ещё требуют проверки.

Для C11 подготовлен полный dependency-free Node HTTP fixture, Dockerfile, `.dockerignore` и Compose. Команды используют конкретный `proctolearn-study-web:local`; base image должен уже быть локально либо отдельно разрешён к загрузке. Docker/WSL не запускался автором пакета. Не требуется большой образ, модель или GPU для структурной CI-проверки.

Для всего пакета выполнены **1290 проверок правильного/неправильного ответа и 645 malformed-проверок** через реальные функции deterministic grader и DTO. Все прошли. Это доказывает технический scoring, а не качество или педагогическую валидность вопросов.
