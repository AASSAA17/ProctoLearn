Transcript (Kazakh):
HTML құжатының түбірі — html. head ішінде title және charset сияқты
метадеректер сақталады. body ішінде пайдаланушы көретін мазмұн орналасады.
h1 негізгі тақырыпты, p абзацты белгілейді. HTML құрылымы мазмұнның
мағынасын түсіндіреді, ал CSS оның көрінісін басқарады.

Transcript (English):
The HTML document root is html. The head contains metadata such as title
and charset. The body contains visible page content. h1 marks a main
heading and p marks a paragraph. HTML conveys structure and meaning;
CSS controls presentation.
