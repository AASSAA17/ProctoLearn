# Predictive Maintenance — зертханалық жұмыстар (3-нұсқа)

Бұл папка 6–9 зертханалық жұмыстарға арналған.

- №6: деректерді дайындау және масштабтау (бастапқы код чатта берілген; файл әлі жүктелмеді).
- №7: классикалық классификация (бастапқы код чатта берілген; файл әлі жүктелмеді).
- №8: K-Means кластерлеу (Colab нұсқасы бар; файл әлі жүктелмеді).
- №9: MLP нейрондық желісі (`lab09_variant3_mlp.ipynb`).

№9 жұмысын іске қосу үшін №6 және №7 жасаған `predictive_maintenance/data/` және `models/` артефакттары қажет. Нәтижелерді орындамай тұрып дайын деп есептеуге болмайды.
